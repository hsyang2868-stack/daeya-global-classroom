# 대야초 지구촌 탐사대

군산 대야초등학교 6학년 사회 수업 자료입니다.

## 2026-11-12 보완

- 자료를 근거로 푸는 3문항: 답 선택 확인, 오답 재시도, 정답·해설.
- 해결안 작성: 문제·근거·주체·실천·확인 방법을 정리하고 인쇄/PDF 저장.
- 학생/교사 화면 구분과 활동별 관찰 기준, 교육과정 출처 안내.
- 학생 답안과 학습 상태는 서버로 전송하거나 브라우저 저장소에 보관하지 않습니다. 새로고침하면 지워집니다.
- 기존 PDF 4종은 그대로 유지했습니다. 새 기능은 웹에서 제공합니다.

교육과정 MCP는 원 제작자가 활용했다고 설명했으나 당시 호출 기록은 공개 저장소에서 확인되지 않았습니다. 새 조회 기록을 만들어 넣지 않았으며, 확인 가능한 교육청 자료와 검토 한계를 교사 화면에 명시했습니다. NCIC 고시 원문·쪽수 직접 대조는 후속 확인 항목입니다. 자체 확인 기준을 국가 공식 성취수준으로 표시하지 않습니다.

## 실행 및 배포

`site/index.html`을 브라우저에서 열 수 있습니다. 기존 GitHub Actions는 `main` 변경 시 `site/`를 배포합니다. 로컬 검토본은 자동으로 원격 저장소에 반영되지 않습니다.
